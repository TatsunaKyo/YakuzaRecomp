# Third-party sources

The native IOP probe links [PS2Recomp](https://github.com/ran-j/PS2Recomp), revision `eb8688b2fd191129f103a39543002c005b33409c`, under GNU GPL version 3. The license text is retained in COPYING. The diagnostic host and project build files are provided under GPL-3.0-or-later.

The AVLZ algorithm and OGREDIR field layout were cross-checked against [YakuzaPythonExtractor](https://github.com/LinuxJessi/YakuzaPythonExtractor), revision `21144751e834a690beb080d3771e8a729fc9e0f5`, by Jessi Ray Godsibb. Its MIT license is retained at licenses/YakuzaPythonExtractor-MIT.txt. The preparation tool adds bounds checks, PAL input verification, portable output-path validation and IRX/ROMDIR inspection. No game bytes were copied into source files or tests.

The opt-in desktop boot target uses PS2Recomp's [raylib 5.5](https://github.com/raysan5/raylib/tree/5.5) dependency (zlib/libpng license), including its bundled GLFW and audio components under their retained upstream licenses. FFmpeg is used for native Linux video decoding under the installed build's applicable licenses; the initial Windows cross-build explicitly disables it. Consult the fetched dependencies' license files when distributing a runtime binary. The synthetic CI fixture is project-owned test code and contains no original game instructions.

For the PAL boot target, tools/prepare_runtime.py creates modified private build copies of the pinned PS2Recomp runtime. It relocates native RPC/TLS/boot helper pools and callback stacks to the project's documented PAL layout and preserves recursive guest calls that yield at their own entry address. The original dependency checkout is preserved. These modifications are part of YakuzaRecomp; upstream copyright/license notices remain in the copied sources. Any distributed runtime must include these adaptations and the corresponding upstream source under the applicable GPL terms.
