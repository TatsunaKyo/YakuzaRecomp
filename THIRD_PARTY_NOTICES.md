# Third-party sources

The native IOP probe links [PS2Recomp](https://github.com/ran-j/PS2Recomp), revision `eb8688b2fd191129f103a39543002c005b33409c`, under GNU GPL version 3. The license text is retained in COPYING. The diagnostic host and project build files are provided under GPL-3.0-or-later.

The AVLZ algorithm and OGREDIR field layout were cross-checked against [YakuzaPythonExtractor](https://github.com/LinuxJessi/YakuzaPythonExtractor), revision `21144751e834a690beb080d3771e8a729fc9e0f5`, by Jessi Ray Godsibb. Its MIT license is retained at licenses/YakuzaPythonExtractor-MIT.txt. The preparation tool adds bounds checks, PAL input verification, portable output-path validation and IRX/ROMDIR inspection. No game bytes were copied into source files or tests.

IPU register/FIFO behavior and MPEG decoding were cross-checked against [PCSX2](https://github.com/PCSX2/pcsx2/tree/7fe1e5525a2c219c119aa9586cee4ceae2f54ce1/pcsx2/IPU), revision `7fe1e5525a2c219c119aa9586cee4ceae2f54ce1`, by the PCSX2 Dev Team. The credited `third_party/pcsx2/mpeg2_vlc.h` and adapted scalar integer IDCT in `third_party/pcsx2/ipu_idct.h` retain GPL-2.0-or-later notices and original libmpeg2 credits to Michel Lespinasse and Aaron Holtzman. See their adjacent README for sources and portability edits. The combined project uses the GPL-3.0-or-later terms in COPYING. Native IPU transport and block decoding are in src/ipu_bitstream.cpp and src/ipu_block.cpp; complete movie presentation remains in development.

The opt-in desktop boot target uses PS2Recomp's [raylib 5.5](https://github.com/raysan5/raylib/tree/5.5) dependency (zlib/libpng license), including its bundled GLFW and audio components under their retained upstream licenses. FFmpeg is used for native Linux video decoding under the installed build's applicable licenses; the initial Windows cross-build explicitly disables it. Consult the fetched dependencies' license files when distributing a runtime binary. The synthetic CI fixture is project-owned test code and contains no original game instructions.

For the PAL boot target, tools/prepare_runtime.py creates modified private build copies of the pinned PS2Recomp runtime. It relocates native helper pools and callback stacks, preserves recursive yields, corrects observed syscall results and VIF boundaries, and connects native IPU transport and MPEG block decoding. tools/prepare_ipu_wait.py preserves verified generated helpers before correcting their native signed-branch widths. Original game instructions and the dependency checkout are preserved. These modifications are part of YakuzaRecomp; upstream copyright/license notices remain in the copied sources. Any distributed runtime must include these adaptations and the corresponding upstream source under the applicable GPL terms.
